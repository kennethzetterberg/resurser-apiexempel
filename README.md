# resurser-apiexempel

This repository contains resources for creating example code using API:s developed by the Swedish Board of Agriculture (Jordbruksverket). Information in Swedish follows.

Här hittar du exempel för att underlätta att skapa exempelkod för API:er i enlighet med arkitekturbeslut.

* Exempel på publiccode.yml file i `publiccode`
* Exempelkod för filbunkens publika API under `filbunken` (OBS! Detta är ett trivialt API så det är på sätt och vis ett leksaksexempel)

Exempelkod bör normal anpassas efter syftet, så för Filbunkenpub-exemplet är det en webbsida eftersom ett syfte med API:et är att det skall vara möjligt att bädda in resultatet i en webbsida. Andra API:er skulle kunna ha mer nytta av andra typer av exempel, som en kommandoradsklient för maskin-till-maskin API:er eller liknande. Viktigt är dock att hålla exempel lätta att läsa och köra.

Normalt ligger en `publiccode.yml` fil i roten på ett repository, så filstrukturen från top-nivå är inte en del av exemplet.
