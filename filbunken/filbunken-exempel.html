Exempelsida för Filbunken-pub

Den här sidan demonstrerar anrop till Filbunken-pub API:et. Filbunken-pub är ett system som levererar filer och förhandsvisningar i form av miniatyrer, främst för bilder som samlats in i samband med markuppföljning eller ajourhållning.

Detta är ett trivialt API som endast har tre anrop — två av vilka fungerar.

  • Hämta versionsinfo (detta anrop fungerar inte)
  • Hämta miniatyr (förhandsvisning / thumbnail)
  • Hämta fil

Filen som används i exemplet har id 1569b8e8-075e-48a3-a873-b28cacc7aa42.
